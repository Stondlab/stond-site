# Site Stond

Site institucional da Stond (stond.com.br). Página única em `index.html`, publicada na Vercel.

O arquivo é gerado a partir de `template.html` no material do projeto (imagens em base64 entram no lugar de `__SIMBOLO__` e `__LOGO__`). O Three.js r128 fica em `vendor/` para não depender de CDN.
